# Cronovelo Addons / Terttus Shop Elements

Custom Elementor widgets for Cronovelo and Terttus with WooCommerce support.

## Updates

The plugin uses Plugin Update Checker and tracks the `main` branch of this public GitHub repository. The plugin header version is the authoritative version used by WordPress. Bump `Version:` in `cronovelo-addons.php` for every deploy to `main`.

Current version: **1.2.1**

After a new version is pushed, WordPress may cache update metadata. Use **Kontrolpanel → Opdateringer → Tjek igen** to force a refresh.
